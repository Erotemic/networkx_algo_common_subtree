networkx\_algo\_common\_subtree.balanced\_isomorphism module
============================================================

The optimized Rust backend remains the default when installed. For small
unweighted inputs, ``impl="reference-rust", node_affinity=None`` invokes the
source-proved structural reference with original token positions. Both general
and ``rooted=True`` modes are supported. The new indexed reconstruction and
Python conversion are independently tested; their source refinement is open.
This reference is exponential and does not provide weighted or equality modes.
Use ``available_impls_longest_common_balanced_isomorphism(include_restricted=True)``
to discover it explicitly. The same option works through
``maximum_common_ordered_subtree_isomorphism`` with original NetworkX vertices.
